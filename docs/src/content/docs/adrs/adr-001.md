# ADR-001: Hybrid architecture
- Status: Active

**In the context of**
- the entire project

**Facing the need for**
- satisfying a lot of different architectural characteristics across different components

**We decided for**
- using a hybrid architecture of [SBA](../adr-002) and [EDA](../adr-003)

**Achieving**
- each component gets an architecture supporting its exact needs

**Accepting that**
- an increasing number of decisions
- two architecture styles
- may need different teams
- may need different skillsets
- may need different tech stacks
