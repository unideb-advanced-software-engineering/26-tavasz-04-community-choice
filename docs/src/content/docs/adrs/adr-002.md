# ADR-002: Service-Based Architecture
- Status: Active

**In the context of**
- *Voting Service*, *Campaign & Idea Service*, *Admin Service*

**Facing the need for**
- independent scaling of individual services based on demand

**We decided for**
- using a Service-Based Architecture

**Achieving**
- a cost-efficient architecture that enables independent scaling of services, preserves strong data integrity, and supports asynchronous processing where needed

**Accepting that**
- tighter data coupling
- less independent deployment
- coarser-grained scalability
- weaker fault isolation
