Alapelvek

A vizuális identitás négy pilléren nyugszik. Minden szín-, tipográfiai- és layout-döntés ehhez igazodik.

Közösség és demokrácia Kerek, összefogó formák; meleg színek; nem hagyja ki a lassú kapcsolatú lakost.
Bizalom és integritás Nyugodt, stabil színek; semmi villódzás; adat és szavazat látható.
Modern digitális állam Tiszta rács, modern sans-serif, takarékos whitespace.
Nyitottság és befogadás Nagy kattintási felületek, magas kontraszt, kor- és képességfüggetlen.
Anti-elvek (tiloslista): Neon színek, szürke tech-stílus, játékos maskot, nagy háttérkép, parallax, dekoratív animáció, kétharmad képernyőt elfedő modal.

Token hierarchia

A rendszer három rétegű. A primitíveket csak a :root réteg használja; a szemantikus tokeneket a komponens tokenek; a komponens CSS pedig csak a saját tokenjeit olvassa.

/* 1. Primitívek – csak :root */
--cc-green-500: #22c55e;
↓
/* 2. Szemantikus tokenek – komponens tokenek */
--cc-cta-bg: var(--cc-green-500);
↓
/* 3. Komponens token – a komponens sajátja */
--cc-button-bg: var(--cc-cta-bg);
↓
/* 4. Komponens CSS */
.cc-btn { background: var(--cc-button-bg); }
Hardcoded érték (pl. #22c55e közvetlenül egy komponensben) tilos. Minden érték tokenen keresztül áramlik.
